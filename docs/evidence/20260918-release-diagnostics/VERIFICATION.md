## 实际模型与 HTTP 服务回放

使用配置的 ccnode Qwen3.8-27B GGUF 模型，真实返回单 token A/B/C/D 与全部候选 logprobs。

- 静态资源校验失败：原状态 RECOVERY_REQUIRED，回滚证据 HOLD_TARGET，模型分类“上线版本运行异常”。
- 数据库迁移失败：原状态 ERROR，诊断记录尚未进入版本部署，模型分类“发布流程或环境”。
- 回滚完成：原状态 ROLLED_BACK，回滚证据 COMPLETED，模型给出运行异常排查类别。
- 最新成功记录：诊断 SUCCESS，不调用模型。

独立启动真实 `server.js`，使用隔离历史副本和隔离任务文件，通过 `/api/history/{id}/diagnose` 验证辅助诊断保存。回放前后所有原始发布状态相同。模型只收到固定结构化枚举，未发送原始日志和发布命令。没有为该验收执行生产发布或回滚。

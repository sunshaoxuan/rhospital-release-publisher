# 生产目标清扫调查报告

## 结论

发布器的游戏、论坛、远端镜像读取、计划生成、执行和历史展示已经统一到当前生产。生产目标由 `release-publisher.config.json` 唯一决定，页面、API、环境变量、IDEA Run Configuration 和本机 SSH 配置不能覆盖正式目标。

## 已完成范围

1. 删除发布器中的退役 Docker Server 注册以及相关文档、测试夹具和历史调查明文。
2. 游戏固定使用 `GAME_PRD2`，论坛固定使用 `FORUM_PRD2`，两者均验证为当前生产主机。
3. 游戏和论坛 Compose 路径由代码固定管理，配置缺失、映射不一致、主机偏离或请求携带覆盖字段时失败关闭。
4. 页面删除 Docker context、SSH 目标和生产编排目录三个可编辑输入，只在发布参数区只读展示解析结果。
5. `/api/remote-tag` 拒绝目标和目录查询参数，计划与执行请求拒绝目标、目录和 Run Configuration 路径字段。
6. 删除 IDEA Run Configuration 读取、TAG 写回、保存 TAG API 和对应兼容分支。发布 TAG 由页面输入并根据远端当前镜像计算建议值。
7. 游戏 Compose 和最终 Swarm 服务增加 `SNAIL_JOB_SERVER_HOST`、`SNAIL_JOB_HOST` 与 `HOST_IP` 当前生产门禁。
8. 本地发布历史执行 v2 migration，保留审计结构并清除连接标识。migration 支持幂等重复执行和显式 rollback。

## 发布路径核对

游戏配置、游戏远端镜像、游戏计划、论坛配置、论坛远端镜像和论坛计划均解析到当前生产。生产现场只读扫描确认游戏 Compose、Swarm 环境和论坛 Compose 不含退役连接标识。业务仓库 `origin/master` 同样不含这些标识，发布器已经解除对其他开发分支 IDEA 文件的依赖。

## UI 验收

浏览器在运行提交 `195451b5` 上检查游戏与论坛切换。两种目标均成功生成流程并读取远端镜像，控制台 warning 和 error 为 0。三项目标编辑字段均不存在。

本次没有生成正式发布任务，没有构建或上传镜像，没有修改生产 Compose，也没有触发 Swarm 或论坛容器替换。生产检查均为读取配置、服务环境和当前镜像。

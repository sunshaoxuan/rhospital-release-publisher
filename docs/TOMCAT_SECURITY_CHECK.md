# Tomcat安全发布检查

触发：应用release-impact.json同时选择verify-game-tomcat-image与verify-game-tomcat-runtime。仅选其一时计划失败。
输入：固定提交的pom.xml唯一tomcat.version、目标镜像及目标Swarm服务。版本必须为10.1.59或更新的10.1补丁，变量、重复声明或其他版本系列失败关闭。
流程：目标镜像构建验证后、上传前，用无网络临时容器检查/app/app.jar。正式final-runtime-check通过后，选择唯一健康目标容器，验证镜像标签和同一JAR清单。
输出：tomcat_security_version=PASS及版本；日志仅包含组件版本。缺失、重复、旧版本混入、错误镜像或健康实例数量异常使检查失败。
验收：npm test；真实Shell夹具覆盖正确、缺失、重复及混合版本；计划测试验证固定提交、配对和切换前后顺序。
回滚：撤销本次代码与文档提交；仍引用新检查键的应用发布计划会失败，需同步使用已验证的旧发布评估。发布器检查本身不变更生产应用。
